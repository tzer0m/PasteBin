# PasteBin

[![Deploy](https://github.com/tzer0m/PasteBin/actions/workflows/deploy.yml/badge.svg)](https://github.com/tzer0m/PasteBin/actions/workflows/deploy.yml)

A simple self-hosted pastebin — paste text, get a link, share it. Built with ASP.NET Core Razor Pages and PostgreSQL, authenticated via Pocket ID (OIDC).

Live at [pb.tzer0m.co.uk](https://pb.tzer0m.co.uk).
